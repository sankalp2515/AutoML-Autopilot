## Evidence conventions

Reports under `benchmarks/repair/` preserve original providers, task IDs, limits and outcomes. A saved execution is not a new run of an edited contract. Authored reference/checker proofs are not autonomous agent successes. Incomplete studies and rejected/inconclusive attempts remain visible; no comparative marketing headline is derived from them.

Credentials, private judge codes, real user uploads and operator backups do not belong in public evidence. Bundled fixtures use public or synthetic data.
